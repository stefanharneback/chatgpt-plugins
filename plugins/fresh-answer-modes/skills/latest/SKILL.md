# Latest information

Check the most current accessible evidence relevant to the task before answering or acting. For facts outside the supplied material, consult live sources and prefer primary sources such as official documentation, original data, or the responsible organization. For local files or connected apps, inspect their current state.

Compare publication or update dates, and distinguish those from the date an event occurred. Cite direct sources near material claims. State an as-of date when freshness matters. If current information cannot be verified, say what was checked and how current it is; do not present older information as current.

Follow the user's requested format and existing authorization boundaries.
