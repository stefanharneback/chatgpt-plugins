Fresh Answer Modes Privacy Policy

Last updated: 2026-10-01

Publisher: STEFAN SIVERT HARNEBÄCK

This policy covers the Fresh Answer Modes plugin and its three skills: latest, latest-short, and latest-short-nochange.

What the plugin does

The plugin contains static instructions and an icon. It guides ChatGPT or Codex to check current sources, cite material claims, and provide a full, concise, or concise read-only answer. It has no publisher-operated server, account connection, analytics, or independent data store.

Personal data

The publisher does not receive or collect users' prompts, conversations, answers, files, account details, or tool results through this plugin. The plugin does not send data to a service operated by the publisher.

ChatGPT or Codex processes the requests and content that users make available. Enabled tools may process search terms or access sources to carry out a request. These services process data under their own privacy notices and the user's permissions.

Purpose and recipients

The purpose of any processing performed by the host and its enabled tools is to answer the user's request with current evidence. The recipients depend on the host and tools used in the conversation. The publisher does not receive that information through the plugin.

Retention

The publisher keeps no plugin-generated conversation records, personal data, files, or usage logs. Retention by ChatGPT, Codex, and enabled tool providers is governed by their own policies and settings.

User controls

Users can stop invoking the skills, disable or uninstall the plugin, and manage tool permissions and data controls in the host product. The latest-short-nochange skill instructs the assistant to avoid changes to files and external records. It is a workflow instruction; the host's actual permissions still apply.

Because the publisher has no copies of conversation data, requests about access to or deletion of data held by ChatGPT, Codex, or tool providers should be directed to those services.

Policy website

This policy page is hosted on GitHub Pages. GitHub logs visitors' Internet Protocol (IP) addresses for security purposes, as described in its Privacy Statement. The publisher adds no analytics, advertising, forms, or tracking scripts to this website.

Contact

Questions about the plugin or this policy can be raised through the public issue tracker. Do not post personal information or conversation contents there.
